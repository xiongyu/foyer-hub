# 开发路线

1. **PC 开发基线**：宿主以 localhost HTTP 服务运行，PC 网页使用能力清单展示可用操作。内置模拟插件可用于完全离线开发；站点适配器单独安装。优先验证操作权限、超时、失败状态及插件启停。
2. **插件平台首版**：先用两个模拟插件验收使用中升级、卸载和回退；再实现本地安装事务及断电恢复；最后接入公开目录、私有授权来源、离线包和 PC 管理页。模拟独占设备移交通过后再测试真实适配器。[插件中心规范与验收条件](plugin-center.md)
3. **来访功能**：设备插件发出来访事件，业务插件负责合并同一次通知、等待计时、接听和挂断。多端共享一个会话，一端接受后其它端停止响铃。未来的媒体插件通过 WebRTC 与客户端交换音视频，事件总线只传状态。
4. **一体式与独立式**：有线 Android 平板自行托管后端，或使用插物业网线的独立 ARM / x86 Linux 主机。生产时只保留一个住户身份在线；前端关闭不影响后端接待。开机、自恢复、双网口绑定及媒体性能逐个平台实测。
5. **多端与新站点**：Flutter 住户客户端覆盖 Android、iOS 和 x86，优先复用 API 与业务模型。新站点只选择其已安装的协议与设备插件，通过同一套能力测试；不支持的能力显示不可用。

PC 开发页和[住户产品界面](ui-design.md)分开验收。设备适配器负责厂商专属收发和本地配置；框架维护人只需要能力契约即可开发通用功能。
